# Live demo

Want to see HonDash before building anything? There is a live demo running at:

* [demo.hondash.com/](http://demo.hondash.com/) to see the dashboard
* [demo.hondash.com/setup/](http://demo.hondash.com/setup/) to play with the [configuration](https://hondash.com/SETUP.html)
* [demo.hondash.com/datalogs/](http://demo.hondash.com/datalogs/) to retrieve the [data log](https://hondash.com/DATALOGGER.html) files

It is the same software that runs in the car, just connected to a simulated ECU instead of a real one. 

## Things to know

* **It is shared.** Everyone visiting the demo sees the same dashboard, so if you change something other visitors will see it too (and someone else may change it while you are looking).
* **You can always go back to the default.** If the configuration ends up in a mess, press the **Reset** button at the bottom of the [setup page](http://demo.hondash.com/setup/) to restore the default one.
* **The keys work too.** The number keys on your computer do the same as the [optional keyboard](https://hondash.com/KEYBOARD.html) in the car while the dashboard is open.
